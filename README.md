# Overview

With this project, I am learning the basics of how to deal with a postgreSQL database and how the folder structure works for a C# application.
As for the folder structure, I especially learned what the data models do and how important they are.

This is a simple C# application that determines the landslide risk in a given city based on the rainfall levels for the past three days on that city. It has a simple Angular FE that allows easy user interaction with the application.

I live in a city where landslides have been a problem for decades and not much has been done about it. This app was something that felt useful for me, even though it is a really simple prototype. This is something I could potentially expand and make useful in the future.
